# Pokemon Portfolio — CLAUDE.md

React + Vite portfolio site styled as a Pokemon Platinum DS battle sequence.

Repo: `github.com/philmantatsky/pokemon-portfolio` (public, pushed 2026-08-27). **Live at `philmantatsky.vercel.app`** — Vercel Hobby, GitHub integration: every push to `main` auto-deploys (~15s); the default `pokemon-portfolio-ten.vercel.app` domain was renamed 2026-08-27 and no longer resolves. Git identity is set **repo-locally** to the GitHub noreply address (`148787581+philmantatsky@users.noreply.github.com`) — global git user.name/email are unconfigured on this machine. `.gitignore` excludes `node_modules`, `dist`, `.playwright-mcp`, `.claude/settings.local.json`, and root-level `/*.png` (debug screenshots; app assets in `src/assets` and `public/` are tracked).

## Stack

- React + Vite
- CSS Modules
- `Press Start 2P` font (loaded via Google Fonts in `index.html`)
- No external state library — plain `useState`

## Running

```sh
npm run dev
```

`vite.config.js` honors a `PORT` env var (falls back to 5173) and `.claude/launch.json` sets `autoPort: true`, so a second dev server can coexist with one already holding 5173.

## Screen Flow

```
start → select → battle → portfolio
```

`App.jsx` controls the screen via `useState('start')`. Each screen is a top-level component.

## Mobile (added 2026-08-28)

Responsive support for portrait phones + tablets. **Desktop (≥ 901px) is byte-identical** — every change is an appended, commented `@media` block at the END of each module file (never edit desktop declarations; the only non-media edits were provably inert: StarterSelection's inline `bottom` → `--drop` custom property, `100dvh` fallback lines after the existing `100vh`, `touch-action: manipulation` on button/a, and the DS TTF moved to `public/` for an index.html `<link rel="preload">` — it's `font-display: block`).

- **Tiers**: phone `≤ 520px` (StartScreen/Battle/Portfolio), StarterSelection uses `≤ 720px` (its 3-card row's clamp minimums total 632px), Portfolio also has a tablet tier `521–900px`.
- **Portfolio phone = the big one**: `--slotH` (and therefore every `--u` sprite in the file) is re-derived from WIDTH — `min((100vw - 6px) * 45/175, (100dvh - 250px)/6 - 5px)` (175u = panel width that fits "LLM DEBATE SIMULATOR"; 250px = vertical chrome budget; both empirically verified 375×812 → u≈2.0, SE 667 → u≈1.47, all 6 slots always fit unscrolled). The party flattens to ONE column **CSS-only**: `.col/.colInner { display: contents }` + `order` on `.slot:nth-child()` to re-interleave DOM order 0,2,4,1,3,5 → visual 1–6 (buttons keep their boxes; `.colRight`'s stagger padding vanishes with its box; arrow-keys still jump ±2 — accepted, touch users). Pinstripe `::before` gets 1-col math (6·slotH + 5·gap, no stagger term).
