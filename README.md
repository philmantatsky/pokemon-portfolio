# Pokémon Portfolio

Personal portfolio site styled as a Pokémon Platinum DS battle sequence — pick a starter, defeat the trainer, and he hands over the portfolio.

**start screen → starter select → battle → party-screen portfolio**

Built with React + Vite (CSS Modules, no state library). The party screen is reconstructed from the real DS game assets: panel sprites, bitmap fonts, and party icons ripped from the games, rendered pixel-exact and scaled in DS-pixel units.

## Run locally

```sh
npm install
npm run dev
```
